商品尽调 Agent

输入商品名称、可选图片、目标市场、竞品链接和目标用户，输出市场机会、竞品商业洞察、产品定位、风险边界与打样决策。

安装

npm install
npm run setup
npm run doctor
npm run dev

不需要 DeepSeek 或 OpenAI API Key。真实联网依赖接收者 Codex 环境中已启用的 web-access Skill，它不是 npm 包。

真实研究

先创建唯一 Research Run，再由 Codex 使用 web-access 收集公开证据，最后执行严格校验、报告生成和导入。完整步骤见 CODEX_USAGE.md。

初始 T21 数据仅用于回归测试。不得把 Fixture、旧 Evidence 或示例报告描述成新的联网结果。

第一性原理机会重构

Atomic Claims 校验完成后，让 Codex 对当前 Run 执行 prepare-first-principles，生成并校验独立的 first-principles-bundle.json。该层拆解需求、供给和约束，形成 2–4 个机会组合与 7–14 天验证计划。完成后执行 npm run workbench -- pre-sample-brief --current --json，生成卖家可读的买样前决策简报。

第一性原理推荐只决定下一步验证方向。缺少正式 SKU、报价、质量、标签、物流或单位经济证据时，Formal SKU 必须保持 HOLD_SUPPLY，Listing 与 Ad Test 继续禁止。
