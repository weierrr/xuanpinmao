# 选品先看人

把不同类目、不同人群的购买行为研究，积累为选品猫长期连载的内容。默认中文写作；栏目名“选品先看人”为可修改的工作名称。

内容读者是选品、产品开发、品牌和电商经营者；研究对象是消费者，包括购买者、使用者、付款者、未购买者、弃用者和退货者。每篇需说明：理解了这些人，会怎样改变目标人群、产品要求、营销表达或下一步验证。

## 按请求选择工作

- **规划栏目或选题**：给出适量候选，每项包含细分类目、目标市场、具体场景、研究问题、经营价值、可能的证据入口、与已有内容的区别。选题标题表达问题，不能预先宣布研究结果。不因规划而启动批量研究或创建定时任务。
- **制作一期**：明确范围，收集证据，形成研究底稿，再转写用户要求的渠道稿件。用户未指定交付范围而要求完整一期时，默认一份研究底稿、三篇不同切口的小红书稿、一篇公众号文章、一份博客归档稿。
- **改写已有报告**：先读取原文及可用来源，复用有依据的结论；只为缺失或过时且影响文章判断的事实补充研究。报告中的未验证方向仍保持原状态。
- **更新旧稿**：读取原稿和新证据，保留旧版本，说明哪些判断被加强、减弱或推翻，并更新受影响稿件。

研究或审查素材时读取 [研究底稿与证据要求](references/research.md)。生成或更新渠道稿件时读取 [栏目与渠道写作](references/editorial.md)。仅做选题规划时不必加载两份参考。

## 范围与执行

1. 从当前对话和已提供素材提取：细分类目、研究市场、目标人群或场景、消费者购买渠道、内容发布渠道、现有证据、交付位置。消费者购买渠道与内容发布渠道是两个字段。
2. 采用用户已给出的选择，不重复确认。缺少目标市场且无法推断时，先推进研究问题与采集计划，只询问会实质改变研究结论的缺项。不要因为用户使用中文或发布小红书就假定研究中国消费者。
3. 优先使用用户指定的报告、资产和来源。开展在线研究时使用当前环境可用的搜索和页面读取工具，并遵循适用的联网技能；不绑定特定浏览器、绝对应用路径或工具名称。
4. 用户要求在选品猫应用内创建或继续正式研究时，使用可用的 `product-research-workbench:open-xuanpinmao` 工作流，遵守其研究对象确认和独立 Run 规则。已有内容改写、栏目规划和普通编辑研究不因本技能强制创建应用 Run。缺少应用能力时可交付文件底稿，但不能宣称应用研究已启动。
5. 默认完成本地草稿。发布、部署、向外部平台写入、购买数据和周期自动执行按用户的实际授权办理；用户已明确授权的操作不重复询问。

## 输出与复用

用户指定位置优先；否则在当前可写工作目录下使用 `output/xuanpinmao-content/<date>-<topic-slug>/`。先检查已有文件，避免覆盖旧稿；修订用新版本文件或独立目录。只生成所需文件，不创建空占位稿。

完整一期建议使用：

- `research.md`：范围、来源记录、研究发现、反证、分群、经营含义与缺口。
- `xiaohongshu.md`：三篇独立短稿及各自配图文字方案。
- `wechat.md`：完整推理文章。
- `blog.md`：可检索、有来源和日期的归档稿。
- `issue.md`：期号或主题、版本、研究市场、渠道、稿件路径、完成状态、未解决问题、相邻选题。只有实际发布后才记录已发布状态和地址。

只要求选题时交付选题表；只要求一个渠道时只交付该稿及必要来源说明。图片文案不是已生成图片；需要成图时再使用可用的图像技能。没有素材或联网失败时交付明确标注的研究计划或概念稿，不能以“研究发现”的语气补齐。

交付前检查：标题是否超出证据、是否混用市场、是否重复拆稿、来源是否能定位、是否有具体选品含义。交付说明给出文件链接、实际完成状态和最值得继续验证的问题；不要把文件创建或格式校验称为市场验证。
