# 研究底稿与证据要求

## 研究的基本单位

细分类目 × 目标市场 × 特定场景或任务。时间范围、购买渠道、产品纳入与排除范围随研究记录。宽类目先提出可研究的切口；不同市场分别整理，只有证据支持时才跨市场比较。

沿以下链条提问：

处境 → 触发事件 → 想完成的任务 → 约束 → 当前替代方案 → 替代方案缺口 → 期望结果 → 付费或不付费的理由。

第一性原理用于拆解问题和识别假设；真实用户资料用于检验。继续追问到能影响产品取舍的具体条件，避免把所有需求归结为“安全感”“便利”“更好的生活”等无法指导行动的词。

## 收集与记录

按问题选来源：评价提供使用经历；社区讨论可能揭示触发与替代方案；访谈补充决策过程；退货与客服资料解释落差；官方资料核对产品或市场事实。竞品文案说明卖家如何表达，不证明用户确实如此思考。搜索摘要用于发现来源，核心结论应读取原文。

每条保留的证据记录：

| 字段 | 要求 |
|---|---|
| 证据 ID | 本期内唯一，可被结论引用 |
| 来源 | 页面标题、直接 URL 或经授权的本地文件定位 |
| 时间与市场 | 采集日；来源发布日期和市场未知时标明未知 |
| 原始观察 | 有上下文的忠实概括；必要时短引文并标注翻译 |
| 对象与场景 | 用户自述或来源可确认的条件，不臆测身份 |
| 支持或反驳什么 | 关联研究问题与结论 ID |
| 局限 | 自选择偏差、商业来源、重复转载、缺少背景等 |

没有实际访问或执行的查询不可记录为已完成。记录关键失败入口与影响即可，不用堆积无关搜索。去重转载和同一用户重复发言，不把一个故事当作多个独立信号。未计数不写“分析了几百条评论”；抽取量、去重后记录量和有效样本量不同。

至少为核心判断寻找独立印证及可能推翻它的材料；来源数量本身不能解决代表性问题。若材料只来自一个平台或少数案例，就明确结论仅适用于观察到的案例，不声称整个市场的分布。

## 综合为需求分群

按任务、触发和约束分群，数量由证据决定，不强行凑三种人物。相同的人可以在不同场景属于不同分群。每组记录：

- 哪种处境的人，在何时需要做什么。
- 目前怎么解决，以及为何仍不满意。
- 期望结果、不可接受的取舍、购买或使用阻力。
- 使用者、决策者和付款者是否不同。
- 支持证据、反证、适用边界、尚待检验的解释。
- 对选品的影响：一个具体产品要求、定位取舍或验证动作。

年龄、性别、收入只在有资料且确实影响决策时加入。不要创造人物姓名、心理独白、采访或人群占比来增加故事感。假设示例必须显式标注。

每条主要判断标记为“直接观察 / 基于证据的推断 / 待验证假设 / 未知”，关联证据 ID，解释从观察到推断的理由。多个抱怨不能推出市场规模；强痛点不能推出愿付价格；内容互动不能推出商品需求或销售额。

## 完成判断

研究底稿应使编辑能够回答：我们看到了什么，如何解释，有何反例，会改变哪项经营判断，还缺什么证据。

若已有足够材料支持一个范围明确的发现，即可写作，不必为了完整画像无限采集。若核心论点只有设想，改成研究问题稿或明确标记的假设讨论；不要生成伪装成研究发现的成稿。

相邻产品是新研究方向。不能仅凭“同一人群也需要”就宣布该产品值得销售；需求、竞争、供应和单位经济仍需各自验证。
